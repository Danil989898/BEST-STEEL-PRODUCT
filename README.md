Как вносить изменения

Проще всего написать Claude в чате, что нужно изменить: заменить текст, фото, номер, добавить или убрать карточку. Он обновит сайт по той же ссылке.

Если редактируете сами, весь сайт находится в одном файле index.html. Фото встроены в него, поэтому отдельных папок с картинками нет.

Как вывести сайт в поиск Google

Сейчас сайт лежит на адресе claude.ai, и поисковики такие страницы обычно не индексируют. Чтобы сайт находили через поиск:

Скачать файл сайта index.html.
Купить домен, например beststeelproduct.com.ua.
Разместить файл на хостинге (подойдут Cloudflare Pages, Netlify, GitHub Pages или обычный хостинг) и привязать домен.
Добавить сайт в Google Search Console и запросить индексацию главной страницы.
Создать профиль компании в Google Business (Google Maps): так вас находят по запросам вроде «ворота + ваш город».

Для лучшей видимости в поиске можно добавить в сайт описание для поисковиков, название города, robots.txt, sitemap.xml и разметку для местного бизнеса.
